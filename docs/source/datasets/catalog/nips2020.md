# NeurIPS 2020 Task 3/4

NeurIPS 2020 Education Challenge Task 3/4 是 Eedi 平台 2018 年 9 月至 2020 年 5 月中小学数学诊断性选择题的作答数据，包含 948 道题与 4,918 名学生。

## 数据集链接

- 官方竞赛页：[NeurIPS 2020 Education Challenge](https://competitions.codalab.org/competitions/25449)
- 数据下载：[data.zip](https://dqanonymousdata.blob.core.windows.net/neurips-public/data.zip)

## 数据规模

| 指标 | 数值 | 口径 |
| --- | --- | --- |
| Task 3/4 训练作答记录 | 1,382,727 | 官方 `data.zip` 中 `train_data/train_task_3_4.csv` 的数据行数 |
| Task 3/4 训练学生数 | 4,918 | 同一文件 `UserId` 去重计数 |
| Task 3/4 题目数 | 948 | 同一文件 `QuestionId` 去重计数 |

本页仅统计 Task 3/4 训练文件，不合并 Task 1/2 数据。

## 字段

以下字段与官方 `data.zip` 中对应 CSV 的表头一致。

### 作答日志（`train_data/train_task_3_4.csv`）

| 字段名称 | 数据类型 | 说明 |
| --- | --- | --- |
| `QuestionId` | Integer | 题目编号 |
| `UserId` | Integer | 学生编号 |
| `AnswerId` | Integer | 答题事件编号，用于关联答题元数据 |
| `IsCorrect` | Integer | 是否答对，1 为正确，0 为错误 |
| `CorrectAnswer` | Integer | 标准答案选项编号，取值 1 至 4 |
| `AnswerValue` | Integer | 学生选择的选项编号，取值 1 至 4 |

### 答题元数据（`metadata/answer_metadata_task_3_4.csv`）

| 字段名称 | 数据类型 | 说明 |
| --- | --- | --- |
| `AnswerId` | Integer | 答题事件编号 |
| `DateAnswered` | Datetime | 作答时间，精确到分钟 |
| `Confidence` | Integer | 学生自评信心百分比，0 表示随机猜测，100 表示完全确定 |
| `GroupId` | Integer | 教学班级组编号 |
| `QuizId` | Integer | 测验卷编号 |
| `SchemeOfWorkId` | Integer | 教学计划编号 |

### 题目元数据（`metadata/question_metadata_task_3_4.csv`）

| 字段名称 | 数据类型 | 说明 |
| --- | --- | --- |
| `QuestionId` | Integer | 题目编号 |
| `SubjectId` | List[Integer] | 与题目关联的知识主题编号列表 |

题目对应的图片位于发布包的 `data/images/` 目录。

### 学生元数据（`metadata/student_metadata_task_3_4.csv`）

| 字段名称 | 数据类型 | 说明 |
| --- | --- | --- |
| `UserId` | Integer | 学生编号 |
| `Gender` | Integer | 性别，0 为未指定，1 为女性，2 为男性，3 为其他 |
| `DateOfBirth` | Date | 出生日期，取当月第一天 |
| `PremiumPupil` | Boolean | 是否因经济困难符合免费校餐或学生津贴资格 |

### 知识主题树（`metadata/subject_metadata.csv`）

| 字段名称 | 数据类型 | 说明 |
| --- | --- | --- |
| `SubjectId` | Integer | 知识主题编号 |
| `Name` | String | 知识主题名称 |
| `ParentId` | Integer | 父级主题编号 |
| `Level` | Integer | 主题层级 |
